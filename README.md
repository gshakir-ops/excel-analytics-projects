## 🚀 How to Use

### 1. Download Files
All Excel files are available in the **[Releases](../../releases)** section of this repository.

### 2. Enable Macros
When opening `.xlsm` files:
1. Click **"Enable Content"** when prompted
2. Or: **File → Options → Trust Center → Trust Center Settings**
3. Select **"Enable all macros"** (for trusted files)
4. Click **OK**

### 3. Explore the Workbooks

**Start Here**: Navigate to the **Dashboard** sheet for an executive summary

**Go Deeper**: Check the **Pivot** sheet for detailed multi-dimensional analysis

**View Details**: Open **Chart** sheets for individual visualization focus

**Review Source**: Examine the **Data** sheet for raw data and source values

### 4. Modify & Experiment
- All worksheets are unlocked for exploration
- Modify pivot tables to test different analyses
- Update chart source data to experiment
- Review VBA code: **Alt+F11** (opens Visual Basic Editor)
