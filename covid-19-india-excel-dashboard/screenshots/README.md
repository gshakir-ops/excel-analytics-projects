# Screenshot Guide

This folder is the visual layer of the GitHub project.

## Recommended Screenshot Set

| File | What to capture |
|---|---|
| `01-dashboard.png` | Full dashboard view, including title and KPI/ranking sections |
| `02-data-overview.png` | Source `Data` sheet with column headers and several rows |
| `03-pivot-analysis.png` | Supporting pivot / summary analysis |
| `04-summary-analysis.png` | Any dedicated summary or insight sheet |
| `05-workbook-overview.png` | Workbook tabs or a clean overview of the Excel file |

## Rules for Portfolio Screenshots

Use screenshots from the actual workbook. Keep text readable, avoid excessive empty space, and crop out unrelated desktop/UI elements.

The project README intentionally includes a screenshot section so a recruiter can understand the project before opening Excel.

After uploading a screenshot, add its Markdown image link to the project README.
